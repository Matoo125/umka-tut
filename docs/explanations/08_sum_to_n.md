# Exercise Sum to N (`08_sum_to_n.um`)

### 🎯 Objective
Calculate the arithmetic series sum 1 + 2 + ... + N.

### 🧠 Core Concepts
- Loop accumulation pattern.
- Mathematical equivalence with Gauss formula: `n * (n + 1) / 2`.

### ⚖️ Umka vs Lua
- Both support direct loop accumulation or the closed-form formula.

### ⚠️ Common Pitfalls
- Handling `n = 0` or negative numbers gracefully.
